# Requerimientos actualizados — SHT_art

## Blog
- El administrador debe crear, editar, guardar como borrador, publicar y eliminar entradas.
- Los visitantes pueden consultar publicaciones publicadas.
- Las cuentas registradas pueden dar me gusta y comentar.
- El administrador puede ocultar o eliminar comentarios.

## Compra
- El checkout debe mostrar contacto, entrega, facturación, pago y resumen.
- El usuario debe indicar contacto, nombre, apellidos, RUT, región, comuna y datos de entrega.
- Se permite envío a domicilio o retiro en punto indicado.
- Debe mostrarse subtotal, descuento, despacho y total.
- La versión actual registra transferencia bancaria manual; no procesa pagos en línea.
